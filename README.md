# Tugas-NLP-RNN-vs-LSTM-vs-Transformer-evaluation-
Proyek ini bertujuan untuk mengevaluasi dan membandingkan kinerja tiga arsitektur jaringan saraf yang populer dalam pemrosesan bahasa alami (NLP): *Recurrent Neural Network* (RNN), *Long Short-Term Memory* (LSTM), dan *Transformer*. Ketiga model ini dilatih untuk tugas analisis sentimen pada dataset ulasan film IMDB.
